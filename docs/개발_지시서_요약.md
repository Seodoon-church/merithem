# LUMI+ 플랫폼 개발 지시서 요약

## 1. 프로젝트 개요

### 목적
LUMI+ 뷰티 디바이스 구매 고객을 위한 종합 관리 플랫폼 개발. AI 기반 피부 진단, 구독형 화장품 배송, 사용 기록 관리 등의 서비스를 통합 제공.

### 개발 범위
- 웹 플랫폼 (반응형 디자인)
- 관리자 대시보드
- AI 피부 진단 서비스 연동
- 구독 관리 및 결제 시스템

### 기술 스택

| 분류 | 기술 |
|------|------|
| Frontend | React 18.2, TypeScript 5.0, TailwindCSS 3.3, React Query, Zustand |
| Backend | Node.js 20 LTS, Express 4.18, TypeScript 5.0 |
| Database | PostgreSQL 15, Redis 7.0 |
| Infrastructure | AWS (EC2, RDS, S3, CloudFront, Route53) |
| 외부 연동 | 토스페이먼츠 API, AI 진단 API (자체 개발), i18next |

### 개발 일정

| 단계 | 기간 | 주요 내용 | 담당 |
|------|------|-----------|------|
| Phase 1 | 1-3개월 | 기본 플랫폼 구축 | Full Stack 팀 |
| Phase 2 | 4-6개월 | AI 진단 연동 | AI + Backend 팀 |
| Phase 3 | 7-9개월 | 구독 서비스 | Full Stack 팀 |
| Phase 4 | 10-12개월 | 글로벌 확장 | 전체 팀 |

## 2. 시스템 아키텍처

### 3계층 아키텍처
- **Presentation Layer**: React + TailwindCSS
- **Business Logic Layer**: Node.js + Express
- **Data Layer**: PostgreSQL + Redis

### AWS 인프라 구성

| 서비스 | 용도 및 스펙 |
|--------|--------------|
| EC2 | 웹 서버 (t3.medium 이상) / Auto Scaling Group 구성 |
| RDS | PostgreSQL 15 (db.t3.large) / Multi-AZ 배포 |
| ElastiCache | Redis 7.0 (cache.t3.micro) / 세션 및 캐시 관리 |
| S3 | 파일 저장소 (사용자 이미지, 진단 이미지) |
| CloudFront | CDN / 정적 파일 배포 |
| Route53 | DNS 관리 |

### 보안 요구사항
- HTTPS 필수 (SSL/TLS 인증서)
- JWT 기반 인증 (Access Token 15분, Refresh Token 7일)
- 비밀번호 암호화: bcrypt (salt rounds 10)
- 개인정보 암호화: AES-256-GCM
- API Rate Limiting: IP당 분당 100요청
- CORS 정책 적용
- SQL Injection 방지: Parameterized Query
- XSS 방지: 입력값 Sanitization

## 3. 데이터베이스 설계

### 주요 테이블

#### users (사용자)
- user_id (UUID, PK)
- email (VARCHAR(255), UNIQUE, NOT NULL)
- password_hash (VARCHAR(255), NOT NULL)
- name (VARCHAR(100), NOT NULL)
- phone (VARCHAR(20))
- language (VARCHAR(10), DEFAULT 'ko')
- created_at (TIMESTAMP, DEFAULT NOW())

#### devices (디바이스 등록)
- device_id (UUID, PK)
- user_id (UUID, FK, NOT NULL)
- serial_number (VARCHAR(50), UNIQUE, NOT NULL)
- model (VARCHAR(50), NOT NULL)
- nickname (VARCHAR(100))
- registered_at (TIMESTAMP, DEFAULT NOW())

#### skin_diagnoses (피부 진단)
- diagnosis_id (UUID, PK)
- user_id (UUID, FK, NOT NULL)
- image_url (TEXT, NOT NULL)
- skin_type (VARCHAR(50))
- concerns (JSONB)
- ai_analysis (JSONB)
- diagnosed_at (TIMESTAMP, DEFAULT NOW())

#### subscriptions (구독 정보)
- subscription_id (UUID, PK)
- user_id (UUID, FK, NOT NULL)
- plan_type (VARCHAR(50), NOT NULL)
- status (VARCHAR(20), NOT NULL)
- next_billing_date (DATE)

## 4. API 명세

### 인증 API
- `POST /api/auth/register` - 회원가입
- `POST /api/auth/login` - 로그인

### 디바이스 API
- `POST /api/devices` - 디바이스 등록
- `GET /api/devices` - 내 디바이스 목록

### 피부 진단 API
- `POST /api/diagnoses` - 진단 요청 (multipart/form-data)
- `GET /api/diagnoses/history` - 진단 이력

### 구독 API
- `POST /api/subscriptions` - 구독 신청
- `GET /api/subscriptions/me` - 내 구독 정보
- `PUT /api/subscriptions/{id}` - 구독 플랜 변경

### 디자인 시스템

#### 컬러 팔레트
| 색상명 | HEX 코드 | 용도 |
|--------|----------|------|
| Primary (LUMI Blue) | #1E3A8A | 주요 버튼, CTA |

#### 타이포그래피
| 스타일 | 크기 | 폰트 무게 |
|--------|------|-----------|
| H1 (페이지 제목) | 32px | Bold (700) |
| H2 (섹션 제목) | 24px | SemiBold (600) |
| Body | 16px | Regular (400) |
| Caption | 14px | Regular (400) |

### 공통 컴포넌트
- **Button 컴포넌트**: primary, secondary, outline, ghost variants
- **Input 컴포넌트**: text, email, password, tel, date types
- **Card 컴포넌트**: 정보 그룹화 컨테이너
- **Modal 컴포넌트**: 사용자 주의 집중 오버레이

### 페이지별 개발 요구사항

#### 홈 페이지 (/)
- 히어로 섹션: LUMI+ 소개 + CTA 버튼
- 기능 소개: 3단 레이아웃 (진단/구독/커뮤니티)
- 반응형: 모바일 1단, 태블릿 2단, 데스크탑 3단

#### 진단 페이지 (/diagnosis)
- 이미지 업로드: Drag & Drop + 파일 선택
- 진단 중 로딩: 프로그레스 바 + 애니메이션
- 결과 표시: 차트 + 상세 분석 + 추천 제품

#### 구독 페이지 (/subscription)
- 플랜 비교: 카드형 레이아웃
- 결제: 토스페이먼츠 위젯 연동
- 구독 관리: 변경/일시중지/해지

## 6. 백엔드 개발 가이드

### 프로젝트 구조
```
src/
├── controllers/
├── services/
├── repositories/
├── middleware/
├── utils/
└── config/
```

### 인증 미들웨어
- JWT 검증 로직 구현
- Access Token 만료 시 Refresh Token 검증
- 인증 실패 시 401 Unauthorized 응답

### 파일 업로드
- Multer 사용 (메모리 저장소)
- 파일 타입 검증: image/jpeg, image/png만 허용
- 파일 크기 제한: 10MB
- S3 업로드 후 URL 반환

### AI 진단 API 연동
- 이미지를 AI 서버로 전송
- 분석 결과 JSON 파싱
- DB 저장 및 사용자에게 응답

### 결제 연동
- 토스페이먼츠 API 연동
- 결제 승인 후 구독 상태 업데이트
- 웹훅 처리: 결제 실패/취소 이벤트
- 정기 결제 스케줄링

## 7. 국제화(i18n) 구현

### 프론트엔드 i18n
- 라이브러리: react-i18next
- 번역 파일 위치: `src/locales/{lang}/translation.json`
- 지원 언어: ko (한국어), en (영어), ja (일본어)
- 브라우저 언어 자동 감지
- 언어 변경 버튼 (헤더 우측 상단)

### 백엔드 i18n
- 라이브러리: i18next
- 에러 메시지 다국어 지원
- 이메일 템플릿 다국어 지원
- Accept-Language 헤더 기반 언어 선택

## 8. 테스트 및 배포

### 테스트 요구사항
- **단위 테스트**: Jest (Backend), Vitest (Frontend), 커버리지 80% 이상
- **통합 테스트**: API 엔드포인트 테스트 (Supertest)
- **E2E 테스트**: Playwright로 주요 사용자 시나리오 테스트

### CI/CD 파이프라인
- GitHub Actions 워크플로우
- 코드 푸시 시 자동 테스트 실행
- Lint 검사 (ESLint, Prettier)
- TypeScript 타입 체크

### 배포 프로세스
- **개발 환경**: develop 브랜치 머지 시 자동 배포 (dev.lumi-plus.com)
- **운영 환경**: main 브랜치 머지 시 수동 배포 승인 (www.lumi-plus.com)
- Blue-Green 배포 전략

### 모니터링
- 애플리케이션 로그: Winston + CloudWatch Logs
- 에러 트래킹: Sentry
- 성능 모니터링: New Relic 또는 DataDog
- 알림: Slack 연동
